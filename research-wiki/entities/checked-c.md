# Checked C

**Kind:** system

A C dialect that adds checked pointer types and bounds annotations, giving safety with little runtime overhead. Adoption stalled because porting was manual. [[msa-icse-2025]] uses LLMs to do that porting. Its closest upstream relative is [[clang-bounds-safety]].
