# Fil-C

**Kind:** system

A memory-safe implementation of C: a Clang fork with its own ABI and a runtime cost, which the community is already using to build real packages ([[hn-fil-c]]). It enforces safety at runtime and does not prove anything, which puts it in the same family as [[cheri]].
