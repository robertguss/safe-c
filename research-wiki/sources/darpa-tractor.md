# DARPA TRACTOR program page

**Date:** 2024 (program page, accessed 2026-10-14)  
**URL:** <https://www.darpa.mil/research/programs/translating-all-c-to-rust>  
**Raw:** `raw/articles/darpa-tractor.md`

## What it claims

DARPA's position is that 'it's not enough to rely on bug-finding tools'. The preferred approach is a safe language that rejects unsafe programs at compile time. TRACTOR aims for automatic C-to-Rust translation at the quality of a skilled Rust developer, combining static and dynamic analysis with LLMs. MIT Lincoln Laboratory runs the test and evaluation.

## What it adds

The strongest institutional argument against the project's premise. The project has to answer it directly. See [[safe-c-approaches-compared]].
